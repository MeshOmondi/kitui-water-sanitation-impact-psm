# Propensity Score Matching Impact Evaluation of a Water and Sanitation Project

## Project Overview

This project evaluates the impact of a water and sanitation intervention in Kitui County, Kenya, using a **Propensity Score Matching (PSM)** approach.

The analysis examines differences in household water-related outcomes between households exposed to the intervention and comparable households that did not receive the intervention.

## Research Objective

The main objective is to estimate the impact of the water and sanitation intervention on household water-related outcomes.

The analysis focuses on comparing outcomes between treated and matched comparison households while accounting for observable differences between the two groups.

## Evaluation Methodology

The project applies **Propensity Score Matching (PSM)** to estimate treatment effects.

The analysis involves:

- Estimating propensity scores
- Assessing treatment and comparison groups
- Matching observations based on observable characteristics
- Assessing covariate balance before and after matching
- Estimating treatment effects among matched observations
- Comparing matched and unmatched outcomes
- Conducting robustness checks

## Analysis

The Stata analysis includes:

- Data preparation and cleaning
- Descriptive statistics
- Treatment-group assessment
- Propensity score estimation
- Common-support assessment
- Matching procedures
- Covariate balance diagnostics
- Matched-sample analysis
- Average Treatment Effect on the Treated (ATT)
- Robustness checks
- Interpretation of treatment effects
- Data visualization
